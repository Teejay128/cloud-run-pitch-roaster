02 • CORE CONCEPT

What Is Google Cloud Run?

Managed serverless compute that runs stateless containers directly on Google's infrastructure.

📦

Any Language or Binary

Package Node.js, Python, Go, Rust, Java, or custom Linux binaries into a container. If it listens on a port, it runs on Cloud Run.

📉

Scales 0 → N Instantly

Scales out to hundreds of instances on traffic spikes and scales down to zero when idle so you pay nothing for unused capacity.

🔒

Zero Infra Ops

Automatic TLS certificates, global load balancing, health checks, and IAM-secured service-to-service networking out of the box.

04 • CONTAINER CONTRACT

The Cloud Run Runtime Contract

Three rules every production container must follow to pass health checks and scale cleanly.

RULE 01 • NETWORKING

Listen on 0.0.0.0:$PORT

Cloud Run terminates HTTPS at Google's edge and forwards traffic to $PORT (default 8080). Binding to 127.0.0.1 will fail startup probes. 

const PORT = process.env.PORT || 8080;
server.listen(PORT, '0.0.0.0');
RULE 02 • STATE

Stateless & Ephemeral

Container filesystem writes live in RAM and vanish when instances scale down. Store durable data in Cloud SQL, Firestore, or Memorystore. 

// Workshop demo store:
// Capped 30-item rolling array
const pitches = [];
RULE 03 • LIFECYCLE

Handle SIGTERM Cleanly

Before scaling down an instance, Cloud Run sends SIGTERM (10s window). Close active WebSockets and flush in-flight requests. 

process.on('SIGTERM', () => {
  client.close(1001);
  server.close();
});
05 • SECURITY & REVISIONS

Keyless Cloud Auth & Traffic Splitting

APPLICATION DEFAULT CREDENTIALS (ADC) 🔑

Zero Hardcoded API Keys

Every Cloud Run revision runs with a dedicated IAM Service Account via the local metadata server. SDKs like @google/genai authenticate to Vertex AI automatically—no API key files or leaked secrets. 

const ai = new GoogleGenAI({
  vertexai: true,
  project: process.env.GOOGLE_CLOUD_PROJECT,
  location: 'global',
});

Instant Rollbacks & 50/50 Canaries

Every deploy creates an immutable revision and injects process.env.K_REVISION. Split live audience traffic 50/50 between two AI personas or roll back a bad release in one command.

06 • ARCHITECTURAL SHOWDOWN

Google Cloud Run vs. Vercel

They solve different layers of the stack: container-centric backend compute vs. framework-decomposed frontend hosting.

VERCEL • FRAMEWORK-DECOMPOSED HOSTING

Built for Frontend Velocity

  • • Splits Next.js / React apps at build time into static Edge CDN assets + short-lived serverless functions.
  • • Zero-config Git PR previews and global static asset distribution.
  • • Trade-off: Stateless per-request functions cannot hold persistent WebSocket hubs, long-running background workers, or custom OS binaries.
CLOUD RUN • CONTAINER-CENTRIC COMPUTE

Built for Production Backends

  • • Runs a real Linux container process that stays warm across hundreds of concurrent requests.
  • • Native WebSockets, gRPC, custom apt binaries, and up to 60-minute request timeouts.
  • • Direct VPC and keyless IAM access to Vertex AI, Cloud SQL, Pub/Sub, and BigQuery.

10 • AI EVALUATION PIPELINE

Structured Gemini Output & Zero-Config Fallback 

// index.js — Structured Output Schema
const response = await ai.models.generateContent({
  model: process.env.GEMINI_MODEL || 'gemini-3.8-flash',
  contents: `Founder: ${author}\nStartup Pitch: "${pitch}"`,
  config: {
    systemInstruction: `You are a ${AI_PERSONA}...`,
    responseMimeType: 'application/json',
    responseSchema: {
      type: Type.OBJECT,
      properties: {
        score:    { type: Type.INTEGER, minimum: 1, maximum: 10 },
        verdict:  { type: Type.STRING },
        roast:    { type: Type.STRING },
        category: { type: Type.STRING },
      },
      required: ['score', 'verdict', 'roast', 'category'],
    },
  },
});
1. GUARANTEED JSON CONTRACT

responseSchema forces Gemini to return a typed 1–10 score, verdict badge, category tag, and roast—ready for UI cards and Telegram replies.

2. DUAL AUTH: VERTEX AI OR API KEY

Uses Vertex AI via Cloud Run's service account when GOOGLE_GENAI_USE_VERTEXAI=true, or falls back to GEMINI_API_KEY.

3. RESILIENT WORKSHOP MOCK MODE

If credentials aren't attached yet on a fresh deploy, generateMockEvaluation() returns realistic mock roasts (mode: "mock") instead of throwing 500 errors.

11 • ARCHITECTURAL FIT

Why Pitch Arena Belongs on Cloud Run

01 • REST + WEBSOCKETS ON ONE PORT

Unified HTTP & /ws Server

Express and WebSocketServer share one Node HTTP server on 0.0.0.0:8080. With --timeout=3600 and our 30s heartbeat, audience sockets stay connected for the entire session.

02 • HIGH CONTAINER CONCURRENCY

500 Concurrent Sockets per Instance

Setting --concurrency=500 and --session-affinity lets a single container hold the live audience room in memory and broadcast NEW_PITCH & NEW_COMMENT events instantly.

03 • KEYLESS VERTEX AI + TELEGRAM WEBHOOK

Public HTTPS Ingress + IAM Identity

Cloud Run gives Telegram an instant https://*.run.app/api/webhook/bot endpoint while authenticating outbound calls to Vertex AI using GCP credits via ADC.

04 • LIVE CANARY PERSONA SPLITTING

Configurable AI_PERSONA per Revision

Changing AI_PERSONA in a new revision lets us split traffic 50/50 between a ruthless Silicon Valley VC and an optimistic YC mentor with zero code changes.

12 • HANDS-ON RUNBOOK

Deploy It Yourself in 3 Commands

Launch Live Pitch Arena →
1. Enable Cloud Run, Cloud Build & Vertex AI APIs 
gcloud services enable run.googleapis.com cloudbuild.googleapis.com artifactregistry.googleapis.com aiplatform.googleapis.com
2. Deploy from Source with WebSocket Tuning & Vertex AI 
gcloud run deploy pitch-arena --source . --region us-central1 --allow-unauthenticated --timeout=3600 --session-affinity --concurrency=500 --set-env-vars="GOOGLE_GENAI_USE_VERTEXAI=true,GOOGLE_CLOUD_PROJECT=$(gcloud config get-value project),GOOGLE_CLOUD_LOCATION=global,GEMINI_MODEL=gemini-3.8-flash"
3. Optional: Deploy a 2nd AI Persona & Split Traffic 50/50 
gcloud run deploy pitch-arena --source . --region us-central1 --set-env-vars="AI_PERSONA=overly enthusiastic YC optimist mentor" --tag=optimist --no-traffic && gcloud run services update-traffic pitch-arena --region us-central1 --to-revisions=LATEST=50,optimist=50
